⌨️ New: Command Palette in calctl, taskctl & notectl

If you've used k9s or lazygit, you know the pattern: press a key, type what you want, hit enter. No more memorizing which single letter does what across a dozen screens.

🔹 Press `:` to open it
🔹 Type an action — "new", "sync", "filter" — matches filter live
🔹 ↑/↓ to pick, Enter to run

Under the hood it replays the exact same keypress the shortcut already maps to, so it can never drift out of sync with what the tool actually does — no separate logic to maintain twice.

Four more tools get this same treatment this week. 📸 Screenshots attached: taskctl, calctl, notectl.

👉 https://github.com/aeon022/missionctl
