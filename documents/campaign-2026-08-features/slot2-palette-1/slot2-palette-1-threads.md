⌨️ calctl, taskctl & notectl just got a `:` command palette — same idea as k9s/lazygit.

Press `:`, type what you want ("sync", "new", "filter"), enter. Live-filtered, prefix matches first. No more memorizing which key does what across a dozen views.

It replays the exact same keypress the shortcut already maps to — so it's never out of sync with what the tool actually does.

👉 https://github.com/aeon022/missionctl
