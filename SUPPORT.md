# Support — postctl

## Questions and bugs

- **Bugs and feature requests:** open an [issue](https://github.com/aeon022/postctl/issues). Please include your version (`postctl --version`), OS, and the exact steps.
- **Docs:** https://postctl.sh/docs
- **Email:** hello@abteilung83.com — I answer within 3 to 5 working days. This is a one-person project; there is no 24/7 support.

## Security

Please report vulnerabilities privately, not in a public issue. See [SECURITY.md](SECURITY.md) or write to hello@abteilung83.com.

## Licences and billing
